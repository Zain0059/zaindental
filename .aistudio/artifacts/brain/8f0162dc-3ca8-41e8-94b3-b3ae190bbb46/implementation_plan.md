# سلة موحدة ومشتركة لبورصة الماتريال لكافة أطباء وموظفي العيادة

تم تحويل سلة المشتريات والمستلزمات في بورصة الماتريال من سلة محلية فردية إلى **سلة موحدة ومشتركة للعيادة بالكامل (Collaborative Unified Clinic Cart)**.

---

### مميزات النظام الموحد المطبق:

1. **رؤية وتعديل موحد للجميع**:
   - أي صنف يضيفه أي طبيب أو مساعد يظهر فوراً لدى بقية أعضاء الفريق.
   - يستطيع أي مستخدم زيادة أو إنقاص الكميات أو حذف الأصناف.

2. **مزامنة سحابية ولحظية (Real-time Cloud Sync)**:
   - حفظ السلة مركزياً في قاعدة البيانات السحابية (Supabase) بشكل دائم، فلا تضيع محتويات السلة حتى لو تم إغلاق المتصفح أو عمل تسجيل خروج.
   - بث التحديثات اللحظية عبر قنوات Supabase Realtime و BroadcastChannel لتنعكس التعديلات فوراً على شاشات كافة المستخدمين دون الحاجة لعمل Refresh.

3. **معلومات التعديل الأخير والشفافية**:
   - شريط حالة مزامنة علوي يوضح: اسم الطبيب/الموظف الذي أجرى آخر تعديل وتوقيته وعدد الأصناف.
   - إشعار تنبيهي لطيف يظهر عند قيام أحد الزملاء بتعديل السلة.

4. **إدارة السلة وإفراغها**:
   - إضافة زر "تحديث يدوي 🔄" لسحب أحدث محتويات السلة في أي وقت.
   - إضافة زر "إفراغ السلة 🗑️" مع رسالة تأكيد تحذيرية لحماية السلة المشتركة من الحذف غير المقصود.
   - عند إتمام الطلب وتوليد الفاتورة / الإرسال للواتساب، يوفر النظام خيار إفراغ السلة لبدء أوردر جديد أو الإبقاء عليها.

5. **حفظ بيانات توصيل العيادة المشتركة**:
   - اسم العيادة/الطبيب، أرقام الموبايل، وعنوان التوصيل أصبحت تُحفظ مركزياً ومشتركة بين الجميع فلا يحتاج أي موظف لإعادة كتابتها.
